# 程式地圖：點哪裡，改哪裡

這份文件說明 Lin AI 健身教練的每個畫面、按鈕，分別要到哪個檔案修改。

## 最快的方法：用「找程式」工具

1. 用本機伺服器打開網站，在網址後面加上 `?找程式`，例如：
   `http://127.0.0.1:8000/index.html?找程式`
2. 右下角會出現 **🔍 找程式** 按鈕，按下去打開。
3. 點畫面上任何按鈕、文字或區塊，就會列出：
   - **畫面（HTML）**：在 `index.html` 第幾行
   - **程式（js）**：哪個檔案第幾行在處理它
   - **樣式（css）**：哪個檔案第幾行在設定它的外觀
4. 點列出的那一行，就會複製「檔案:行號」，可以貼到 VS Code 的「前往檔案」（Ctrl+P）。
5. 工具打開時點擊不會觸發原本的功能。要正常操作，再按一次按鈕把它關掉。

沒有加 `?找程式` 時，一般使用者看不到這個工具。

## 資料夾怎麼分

```
fitai-web/
├─ index.html      只放畫面（HTML）。每個區塊上方都有中文註解，寫著程式和樣式在哪個檔案
├─ css/            外觀（顏色、大小、排版），依編號順序載入
├─ js/             功能（按下去會發生什麼事），依編號順序載入
├─ sw.js           離線快取（新增或改名 css/、js/ 檔案時要更新這裡的清單）
├─ backend/        AI 教練的 WHO 知識庫後端（Python）
└─ 程式地圖.md      就是這份文件
```

## 修改時要注意

- **js 檔案的順序不能任意調換。** 所有 js 檔共用同一組變數和函式（例如 `01` 裡的 `$`、`S`、`save`、`toast`），後面的檔案會用到前面的。
  按鈕的 `onclick` 裡呼叫其他檔案的函式沒問題；但如果是「網頁一打開就立刻執行」的程式，只能用到編號比自己小的檔案裡的東西。
- **css 也是後面蓋過前面。** 同一個元素在兩個檔案都有設定時，編號大的那個會生效。
- **新增或改名檔案時，要改三個地方：**
  1. `index.html` 最下面的 `<script defer src="js/…">`（或最上面的 `<link rel="stylesheet" href="css/…">`）
  2. `sw.js` 的 `JS_FILES` 或 `CSS_FILES` 清單，並把 `VER` 加 1
  3. 這份文件
- 想知道網頁有沒有壞掉：按 F12 打開開發者工具，看「Console」有沒有紅色錯誤。
